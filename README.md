# Learning Hub

Self-contained, no-build course app with nine courses:

- Finance & Data Intelligence for Technical Leaders
- Adaptive Leadership & Professional Impact for Technical Leaders
- Investor Thinking: Decisions, Trends and the Thesis Method
- Strategic Foresight: Planning for Multiple Futures
- The Agent Economy: How Software Learns to Pay, Buy and Trade
- Data Foundations for AI Agents: From Pilot to Scale
- Business Model Design for Technical Leaders
- Systems Thinking for Technical Leaders: Fixing Problems That Keep Coming Back
- Storytelling for Technical Leaders: Making Ideas Land

Open `index.html` in any browser. Progress is stored in the browser's localStorage
(key `learning_hub_progress_v1`). Diagrams use Mermaid from a CDN and fall back to
plain text when offline.
